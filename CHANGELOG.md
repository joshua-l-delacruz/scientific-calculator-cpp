# Changelog

Notable project milestones are recorded here. This project did not originally use semantic release tags, so these entries preserve the documented portfolio release sequence rather than claiming a formal package-release history.

## V10.2

- Added a wide desktop layout with independent Scientific and Programmer columns.
- Improved the 64-bit display, section spacing, word-size error recovery and asset versioning.

## V10.1

- Added build, technology, deployment and license badges.
- Expanded recruiter-oriented documentation and the project rationale.

## V10

- Added dedicated API and architecture documentation.

## V9.1

- Added `/api/info`, expanded `/health`, capability metadata and CI coverage.

## V9

- Added programmer history, persistent settings, copy controls and keyboard support.

## V8

- Added 8/16/32/64-bit words, signed and unsigned interpretation, two's complement, arithmetic right shift, rotations and the interactive bit editor.

## V7

- Introduced programmer mode with BIN/OCT/DEC/HEX conversion, bitwise operations and shifts.

## V6

- Improved the production-oriented interface.

## V5

- Added scientific memory and calculation history.

## V4

- Added DEG/RAD trigonometry.

## V3

- Replaced basic evaluation with a custom recursive C++ expression parser.

## V2

- Added scientific functions and constants.

## V1.2

- Improved responsive behavior.

## V1

- Initial scientific calculator.
